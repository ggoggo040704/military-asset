# 🎖️ 군 복무 목돈 모으기 & 전역 후 자금 설계 시뮬레이터

군 복무 중 장병내일준비적금과 매칭지원금(정부 100% 지원)을 통한 목돈 모으기, PX/외출 가계부 관리, 전역 후 꿈과 목표별 자금 설계를 지원하는 원스톱 웹 애플리케이션입니다.

---

## 🛠️ 기술 스택
- **Frontend**: HTML5, Tailwind CSS, JavaScript (Vanilla JS), Chart.js
- **Backend & Database**: Supabase (PostgreSQL, 실시간 클라우드 DB)
- **Deployment**: GitHub + Vercel

---

## 📂 프로젝트 구조
- `index.html`: 메인 웹 페이지 구조 (시뮬레이터, 가계부, 목표 설계 탭)
- `style.css`: 사용자 인터페이스 커스텀 스타일
- `supabase.js`: Supabase 클라이언트 연결 설정
- `app.js`: 핵심 적금 계산 공식, 차트 렌더링, 탭 전환 로직
- `README.md`: 프로젝트 가이드 문서
